PROJETOS 2° ELETRÔNICA B

Os alunos do 2º ano de Eletrônica desenvolveram projetos usando ESP32, Bluetooth, sensores e programação, aplicando na prática os conhecimentos adquiridos no curso.

1° PROJETO FEITO POR: JOÃO

SENSOR DE MOVIMENTO 📢

● Um sensor de movimento detecta quando uma pessoa ou objeto se movimenta em determinado local.

Ele pode enviar um sinal para um ESP32, que então executa uma ação, como acender uma luz, emitir um alerta ou enviar uma informação por Bluetooth.

2° PROJETO FEITO POR: GABRIEL

CONTROLE DE SERVO MOTOR ⚙️

● Projeto desenvolvido utilizando um ESP32 para controlar a posição do servo através de comandos enviados ao microcontrolador.
